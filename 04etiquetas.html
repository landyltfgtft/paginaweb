Etiquetas Semánticas en HTML

Regresar

Una etiqueta semántica es aquella que describe el significado del contenido que encierra, ayudando a que el navegador y los desarrolladores comprendan mejor la estructura de la página.

Principales Etiquetas Semánticas con Ejemplos

<header>
Define la cabecera de la página o sección.
Ejemplo:

Mi Sitio Web

<section>
Divide el contenido en secciones temáticas.
Ejemplo:

Noticias

Últimas novedades del día.

<article>
Se usa para contenido independiente y completo.
Ejemplo:

Artículo de Blog

Este es un artículo independiente.

<aside>
Contiene información complementaria.
Ejemplo:

Publicidad o enlaces relacionados.

<footer>
Define el pie de página.
Ejemplo:

© 2026 Mi Sitio Web

<nav>
Representa la sección de navegación.
Ejemplo:
  • Inicio
  • Introducción
  • Texto
  • Listas
<main>
Indica el contenido principal de la página.
Ejemplo:

Este es el contenido principal.

<search>
Se utiliza para definir un área de búsqueda.
Ejemplo:
<address>
Proporciona información de contacto.
Ejemplo:
Contacto: correo@ejemplo.com
Dirección: Calle Falsa 123, Ciudad
